\# Flask REST Series Tracker



University web application for managing personal TV series using a REST backend.



\## Technologies



\- Python

\- Flask

\- REST

\- PHP

\- MySQL

\- SQL

\- HTML

\- CSS



\## Features



\- User login

\- Display and manage personal series

\- Filter series by title, genre and platform

\- REST-based backend

\- Relational MySQL database

\- PHP-based web interface



\## Project Structure



\- `REST/` - Python Flask REST backend

\- `www/` - PHP and CSS web interface

\- `db/` - MySQL database schema



\## Background



This project was developed as part of a university web technologies course.
